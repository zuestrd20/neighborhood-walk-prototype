關於這裡

場景以起點為中心，設定半徑約 100 公尺的可走範圍。建物、道路、招牌與街道擺設皆為原創概略配置，不代表該地點的實際建築、店家、尺寸或道路位置。

沒有使用 Google 地圖、空照圖、街景畫面或其他測繪資料建立幾何。此原創街區僅供遊戲測試，不可用於導航、勘測或房產判斷。

這是公開的 GitHub Pages 測試版。遊戲不讀取裝置定位，不含分析追蹤；載入網站時會向 GitHub Pages 請求遊戲檔案。

引擎：Three.js（MIT）・原創程序化角色與街區模型
